# dsh-achievement-helper 0.2.0

首个公开稳定版，已通过 [GitHub Release](https://github.com/ghang/dsh-achievement-helper/releases/tag/v0.2.0) 和 [npm](https://www.npmjs.com/package/dsh-achievement-helper/v/0.2.0) 发行；插件榜收录单独办理。后续 README 截图不改写已发布的 tag 和安装包。

成就手记将新的 DSH 使用经历整理为本地个人成就、勋章和历程，并提供主题角色收藏。

- 十套主题、80 个预设角色和独立的清爽扁平/微像素画风，共 20 张本地图集；支持本地上传图片、展示框、佩戴与减少动画。
- 每枚唯一成就提供 1 点，1 点十连，十连至少 SR；同题材每 50 张内必出 SSR，任何 SSR 重置保底。逐卡显示基础概率与包含当前保底的下次十连平均单张概率。
- 预设和自定义成就、角色支持改名与恢复，保留规则、进度、原始获得记录、点数与收藏。自定义成就删除后保留历史和已获得点数。
- 从选定数据源生成 1～6 项成就，结果校验后应用；模型角色创作可加入卡池。只有显式模型生成会发起辅助模型请求，计数、抽卡、外观和调试不调用模型。
- 独立临时调试副本支持快速完成、抽取、佩戴、重置和退出；真实工作与模型工具继续记录真实档案。收藏成就卡采用紧凑布局，适配窄窗口。

包名由 `dsh-achievement-journal` 改为 `dsh-achievement-helper`。运行时 ID、`storages/achievement-journal/`、请求恢复存储键和四个 `achievement_*` 工具保留；新 `/dsh-achievement-helper/api` 与旧 API 别名同时可用。此次重命名不增加模型工具或新数据字段。

升级时先停用目标宿主并备份完整插件存储，在同一 profile 移除旧包后安装新包，保留原存储目录；不要同时加载新旧包。rc.5/rc.6 数据协议兼容。首次保存改名后不能直接降级到 rc.4 或更早版本，恢复原名也不解除限制；降级须恢复对应版本的完整备份，避免覆盖后续活动。[发布与升级步骤](../RELEASING.md)。

验证使用 Node 24.18.1 / 22.19.0、DSH 0.2.1-rc.2 与 Chrome web。Node 22 通过相同源码及同一冻结tgz的解包回归，不重打包；实际候选和宿主结果以本次报告为准。原生desktop、其他平台与宿主版本尚未验证。

只观察启用后的新活动，无历史导入或跨设备合并。缺失用量保持未知，模型报告与用户记录单独标源；成就点用于本地收藏，无付费购买、排行榜或工作质量评分。
