# Changelog

## 0.2.0-rc.4

Add independent flat/pixel appearance selection for all ten themes, with twenty
transparent atlases representing the same eighty character identities. Theme
appropriate effects increase with rarity; uploaded art retains precedence.
Preserve existing archives without a read-time rewrite and isolate appearance
changes in debug copies. Canceling auxiliary generation before dispatch no
longer creates a spurious unknown-usage receipt. Keep the four model tool
schemas unchanged. Downgrading after saving the new preference requires the
matching complete plugin-storage backup.

## 0.2.0-rc.3

Add an exact achievement generation count (1–6, default 3) and deletion of
custom goals while retaining earned records, point spending and durable
identities. Unify theme selection across achievements, character collection,
generation and debug draws; hide other-theme results and equipment until
switching back. Present built-in character names as genre ranks and professions
without rewriting archived canonical cards. Keep schema 2 and existing images.
Recover draws rejected before commit and retain original generation requests
when a start response is uncertain, avoiding accidental duplicate model work.
New artwork is being reviewed as a separate four-style comparison.

## 0.2.0-rc.2

Rename the setup tab to “自定义生成” without changing generation flow. Replace
default vector portraits with ten generated, themed illustration atlases and
make equipment actions visible on ten-pull results. Add browser-only debug
copies with quick completion, draw-and-wear, charms, reset and exit. Debug data
never merges into the real archive; real work continues recording separately.

## 0.2.0-rc.1

Add configurable profile frame heights with live previews, ten complete themes,
and themed character collections. One earned achievement funds one ten-pull;
draws commit point spending, duplicates and guaranteed rarity atomically.
Add model-generated and custom character pool entries, local animated images,
reduced-motion presentation and character equipment. Migrate v1 archives while
retaining earned records, deduplication identities and existing equipment.
Four tools remain, with expanded character and theme parameters.

## 0.1.0-rc.3

Compact responsive layouts and smaller badges/icons. Replace prompt-copy setup
with data-source, theme-direction and template-style selection followed by one
bounded model generation and validated automatic application. Add cancellation,
durable request deduplication and attributed auxiliary usage receipts. Render
equipment as a slim frame next to the account area; preserve the native account
menu. Existing collections and settings are retained on upgrade.

## 0.1.0-rc.2

Freeze archived definitions and guard award creation by active status. Preserve
damaged identity files while showing an unavailable archive instead of failing
the whole host. Recover writer locks only for a proven dead local process.
Keep unsupported/partial observation explicit and drain pending facts on unload.

## 0.1.0-rc.1

First local candidate. A personal achievement journal with three themes,
runtime-observed progression, collectible badges, equipment, model-configured
bounded rules, explicitly attributed milestone reports and quiet feedback.

This candidate is not published. Only the validated web profile is supported.
Four fixed model tools affect model-visible tool declarations on installation;
theme and achievement definition changes do not register new tools.
