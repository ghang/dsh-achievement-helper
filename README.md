# DSH 成就手记

一个轻量的个人成就插件。真实使用积累、文件探索、技能与委派等经历可以变成主题成就；勋章、挂件与历程保存在本地。当前为本地候选，未公开发行。

支持探索、修仙、赛博朋克三套主题。主题改变文案与外观，获得记录和佩戴保持稳定。日常记录和反馈不调用模型；只有用户点击「分析并生成成就」才发起一次有界的辅助模型请求，不代替用户执行工作，不包含排行榜、多人或游戏经济。

## 使用

在 DSH 侧栏底部、用户名区域旁的小边框佩戴带打开「成就手记」，或在设置中打开同名页。首次安装为空档案，完成新的工作回合后开始积累。概览查看等级与最近获得；收藏查看条件与佩戴；历程记录获得和升级。反馈可设为全部、仅解锁或关闭，并可减少动画。布局随容器宽高收紧，适应窄窗口和浏览器缩放。

模型配置页只需勾选数据源、选择主题方向与模板风格，然后点击「分析并生成成就」。插件使用当前会话选中的模型，没有当前会话时使用 DSH 默认模型；不会把主会话历史发送给生成模型。生成结果经结构校验后直接加入档案，无需复制提示词或逐项确认。正常模型用量与实际来源会显示在生成回执里，未知用量不会补零。

也仍可在正常会话中告诉模型：

> 给我配置一套修仙成就，包含探索、协作和这个项目的纪念。先查询成就目录，只配置当前支持的条件。

模型通过四个固定工具工作：`achievement_catalog`、`achievement_query`、`achievement_configure`、`achievement_report`。目录说明实际来源与覆盖；自动事实由插件判定，模型报告和用户记录单独标源。模型不能写原始 token 或直接授予自动成就。

## 数据与边界

只记录启用后的可见活动，不自动导入旧会话。缺 usage 是未知，不推断为零。fork 继承、重复事实和请求重试去重；顺序组合要求可证明的步骤依赖，不拿并发结果的日志排列当执行顺序。命令结束不代表测试通过，文件交付不等于用户验收，Skill 加载不等于正确应用。

档案位于当前 DSH_HOME 的 `storages/achievement-journal/`，含本地身份盐、规则、去重水位、聚合、获得历史和佩戴；不复制源码、会话正文、命令参数或报告正文。生成回执另保留有界任务身份、模型、用量、结果ID和终态，不保存方向文本或原始模型输出。定义标题和说明由用户/模型配置，避免把秘密写入这些字段。只有原子持久化成功的变化才通知。损坏或写失败不会静默清空收藏。

一键生成可取消，应用阶段开始后不再承诺撤销。取消、超时、截断或不合格输出不会应用；重启不自动重发模型请求。后台计数变化只重试本地保存，定义或主题被其他操作修改时保留新配置并拒绝旧生成结果。辅助生成已证明的 token 会单独入账，不伪造完成回合。

首次安装增加四项模型工具，可能使已有长会话的请求前缀缓存变化。建议在任务间隙安装，先使用独立 web profile。修改主题、佩戴或成就定义不会增加工具声明。计数和反馈无需模型调用，用户通过会话配置成就时使用正常模型用量。

## 安装与卸载

使用已构建并验证的本地 tgz，仅安装到 `web` profile：

```sh
dsh plugin --profile web add /absolute/path/dsh-achievement-journal-0.1.0-rc.3.tgz
```

这是本地自研候选，不是市场插件。卸载：

```sh
dsh plugin --profile web remove dsh-achievement-journal
```

卸载停止工具、事件观察和界面；档案保留，重装可恢复。需要清除个人档案时先停止对应宿主，备份后移除上述专用存储目录，不修改 Session 真源。初版没有历史数据迁移或跨设备合并功能。

## 开发与验证

使用 Node 22.19 或 24+。`npm ci --ignore-scripts` 安装锁定开发依赖，`npm test` 验证领域、采集、工具与 HTTP 集成；`npm run build` 干净构建；`npm run check:package` 完整验证源码、构建及实际 tgz 的关键集成。不要在指向运行 profile 的依赖软链上执行安装或构建。

测试只使用合成记录和本机假上游。源码测试与真实宿主安装、浏览器验证分开留证；本地候选不等于公开发行或收费模型质量验收。
